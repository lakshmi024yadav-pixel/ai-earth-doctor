# 🌍 AI Earth Doctor

AI/ML based Environmental Monitoring, Disaster Detection & Sustainable
Land Planning System — BCA Final Year Project.

## Status
Stage 1 of 16 complete: project foundation (Flask app + SQLite schema).

## Requirements
- Python 3.10+ installed and on PATH (Windows: check "Add Python to PATH"
  during install)

## Setup (Windows)
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python database\init_db.py
python app.py
